DOCUMENTACIÓN DEL SHADER RAINDROPS - UNITY 3D URP
=======================================================

DESCRIPCIÓN GENERAL:
Este shader crea un efecto visual de lluvia y gotas de agua en la pantalla, simulando el efecto de mirar a través de una ventana mojada. Está diseñado para ser usado en la cámara del Main Menu.

UBICACIÓN DE ARCHIVOS:
- Shader: Assets/raindrop/Raindrop.shader
- Material: Assets/raindrop/RainDrops.mat
- Prefab de Cámara: Assets/Prefab/RaindropCamera.prefab

COMPONENTES PRINCIPALES:

1. ESTRUCTURA DEL SHADER:
   - Tipo: Shader de Unity (CGPROGRAM)
   - Basado en: Heartfelt shader de Martijn Steinrucken (Shadertoy)
   - Render Type: Opaque
   - LOD: 200

2. PROPIEDADES:
   - iChannel0: Textura de entrada (Albedo RGB) - se usa como fondo

3. FUNCIONES PRINCIPALES:

   a) N13, N14, N:
   - Generan números aleatorios pseudo-aleatorios
   - Usadas para crear variación en las gotas

   b) Saw():
   - Crea una función de diente de sierra
   - Usada para animar la aparición/desaparición de gotas

   c) DropLayer2():
   - Genera una capa de gotas de lluvia
   - Crea gotas principales + estelas + pequeñas gotas
   - Retorna: (intensidad de gotas, estela)

   d) StaticDrops():
   - Crea gotas estáticas que no se mueven
   - Simula gotas que se han quedado en la ventana

   e) Drops():
   - Combina todas las capas de gotas
   - Controla la cantidad de lluvia mediante parámetros

4. SISTEMA DE GOTAS MULTI-CAPA:
   - Capa 0: Gotas estáticas (StaticDrops)
   - Capa 1: Gotas principales móviles (DropLayer2)
   - Capa 2: Gotas secundarias más pequeñas (DropLayer2 escalado)

5. EFECTOS VISUALES:
   - Gotas principales: Círculos de agua con bordes suaves
   - Estelas: Líneas que siguen el movimiento de las gotas
   - Pequeñas gotas: Gotas menores que aparecen entre las principales
   - Desenfoque dinámico: El fondo se desenfoca según la intensidad de lluvia
   - Distorsión: Las gotas distorsionan la imagen subyacente

6. PARÁMETROS DE CONTROL:
   - rainAmount: Controla la cantidad de lluvia (0.0 - 1.0)
   - T: Tiempo de animación basado en _Time.y
   - staticDrops: Intensidad de gotas estáticas
   - layer1/layer2: Intensidad de capas móviles

7. PROCESAMIENTO POST-PROCESAMIENTO:
   - Cambio de color sutil hacia tonos fríos
   - Efecto viñeta en los bordes
   - Fundido de entrada/salida
   - Efectos opcionales de relámpagos

8. CONFIGURACIÓN EN UNITY:
   - El shader se aplica a un material
   - El material se usa en un efecto de post-procesamiento
   - Requiere una textura de entrada (iChannel0)
   - La cámara debe tener configurado el renderizado HDR

9. RENDIMIENTO:
   - Usa funciones de ruido pseudo-aleatorio eficientes
   - Normales calculadas con diferencias finitas (opción de normales baratas disponible)
   - Optimizado para shaders de pantalla completa

10. USO EN EL PROYECTO:
   - Se usa en el Main Menu para crear ambiente de lluvia
   - Se combina con efectos de sonido de lluvia
   - Crea atmósfera inmersiva antes del juego

PARÁMETROS MODIFICABLES:
- Para aumentar lluvia: Aumentar rainAmount
- Para más estelas: Ajustar valores en DropLayer2
- Para cambiar velocidad: Modificar multiplicadores de tiempo
- Para cambiar tamaño de gotas: Ajustar valores de escala en DropLayer2

NOTAS TÉCNICAS:
- El shader requiere Unity 2019.1 o superior
- Compatible con URP (Universal Render Pipeline)
- No requiere texturas externas (todo se genera proceduralmente)
- El efecto es temporal y se actualiza cada frame
